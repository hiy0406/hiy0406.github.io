# 허인영의 인문데이터과학 사이트
서울대학교 [인문데이터과학개론] (2026-1) 수업에서 만든 개인 포트폴리오 사이트입니다.

**공개 주소**: https://hiy0406.github.io

## 구성
- **홈**: 소개와 프로젝트 카드
- **블로그(`_posts/`)**: 수업 중 작성한 글과, 전체 구현 과정을 돌아본 회고 글
- **셜록홈즈 소설 비교(`/compare/`)**: 셜록 홈즈 두 작품의 단어 빈도 비교
- **고딕 소설 비교(`/gothic/`)**: 프랑켄슈타인과 드라큘라 두 작품의 단어 빈도 비교
- **텍스트 분석기(`/analyzer/`)**: 영어 텍스트를 붙여 넣으면 상위 20개 단어를 막대그래프로 표시

## 사용 기술
Jekyll· GitHub Pages· Chart.js· HTML/CSS/JavaScript
